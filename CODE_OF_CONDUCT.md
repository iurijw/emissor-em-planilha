# Código de conduta

Este projeto quer ser um lugar acolhedor para quem usa, relata problemas ou contribui, seja qual for a experiência,
a profissão, a origem ou a identidade de cada pessoa.

## O que esperamos

- Tratar todo mundo com respeito e paciência, inclusive quem está começando.
- Criticar ideias e código, nunca pessoas.
- Aceitar com boa vontade quando um relato ou sugestão não for adiante e explicar o motivo quando for você a decidir.
- Proteger os dados dos outros: nunca publicar informações fiscais, pessoais ou de clientes de terceiros.

## O que não é aceito

- Ofensas, assédio, ameaças, linguagem ou imagens discriminatórias.
- Ataques pessoais e comentários depreciativos.
- Publicar dados privados de alguém sem autorização.
- Spam e propaganda sem relação com o projeto.

## Como relatar

Escreva para **contato@emissoremplanilha.com**. A mensagem é lida pelo mantenedor e tratada com sigilo. Quem
descumprir estas regras pode ter comentários removidos e ser bloqueado no repositório.

Inspirado no [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).
